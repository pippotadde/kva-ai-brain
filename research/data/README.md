Il regolamento (§7, §11) chiede di usare solo dati che abbiamo il diritto di usare. Ogni dataset o documento entra qui **prima** di essere usato.

Regole:
- File piccoli (< 5 MB) in `data/`; quelli grandi in `data/raw/` (non vanno su git) con lo script per scaricarli.
- Niente dati personali veri. Persone e aziende nella demo sono inventate e lo diciamo.
- Dati inventati: segnarli come "sintetici" in questa tabella.
